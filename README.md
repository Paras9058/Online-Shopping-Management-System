# Online Shopping Management System Using MySQL

## Project Overview
The Online Shopping Management System is a database project developed using MySQL. It manages customer details, product information, and customer orders.

## Objectives
- Store customer information.
- Manage product details and stock.
- Maintain customer orders.
- Calculate total sales.
- Retrieve information using SQL JOIN queries.
- Demonstrate stored procedures, functions, and cursors.

## Technologies Used
- MySQL
- MySQL Workbench
- SQL

## Database Tables
1. Customers
2. Products
3. Orders

## Advanced SQL Concepts
- INNER JOIN
- LEFT JOIN
- RIGHT JOIN
- Stored Procedures
- Functions
- Cursors

## Project Features
- Customer record management
- Product and stock management
- Order management
- Total sales calculation
- Low-stock product identification

- Report: Contains the project report.
